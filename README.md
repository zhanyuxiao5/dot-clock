# Dot Clock

[Try here](https://zhanyuxiao5.github.io/dot-clock/)

Dot Clock is an interactive clock with a dial made entirely of dots. Their position, size, number and colour tell the time.

- **Red (hours)** — The position of the highlighted dot indicates the hour.
- **Blue (minutes)** — Each large dot represents 10 minutes and each small dot represents one minute.
- **Yellow (seconds)** — Each large dot represents 10 seconds and each small dot represents one second.
- **Background** — Off-white indicates AM and charcoal black indicates PM.

The clock automatically synchronises with your local time. Pause it and adjust the time to explore how the patterns change.
